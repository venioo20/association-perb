Votre expérience compte

Donner votre avis sur PERB

Vous pouvez témoigner anonymement ou choisir d’afficher uniquement votre prénom ou un pseudonyme. Votre adresse e-mail sert uniquement à vérifier et traiter votre témoignage : elle n’est jamais publiée.

Publication après validation

Les avis ne sont pas publiés automatiquement. PERB les relit avant publication afin de protéger les enfants, les familles et les tiers, et d’éviter la diffusion de données personnelles ou d’accusations nominatives.

Comment souhaitez-vous apparaître sur le site ?

Confidentialité : cette page n’enregistre pas votre témoignage dans une base de données. Après validation du formulaire, votre logiciel de messagerie s’ouvre avec le message préparé pour contact@association-perb.fr. Vous restez maître de l’envoi.
